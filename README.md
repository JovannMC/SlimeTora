# SlimeTora

A program that connects the HaritoraX trackers to the [SlimeVR server](https://slimevr.dev/download), supporting the `HaritoraX 2`, `HaritoraX Wireless` and`HaritoraX Wired` (1.1b/1.1/1.0). Supports `Bluetooth LE` and serial connections (via `Bluetooth SPP` & `GX(6/2)` dongles).

### For ~~support~~ updates, join the Discord server: <https://discord.gg/XdfnKD9QVM>

# Features

- Almost full feature parity with the official softwares - `HaritoraConfigurator` & `Shiftall VR Manager`
- Supports `HaritoraX 2`, `HaritoraX Wireless`, and `HaritoraX Wired` (1.1b/1.1/1.0)
- Supports `Bluetooth LE` and serial connections (`Bluetooth SPP`/`GX(6/2)` dongles)
- Windows, macOS, and Linux support
    - As of now, this is the only method to get HaritoraX trackers to work on Linux and macOS!
- Button bindings to SlimeVR functions (e.g. resets)
    - Read more on the [SlimeVR basics](https://github.com/OCSYT/SlimeTora/wiki/SlimeVR#resets--calibration) wiki page
    - Customizing bindings and support for tap / hold bindings in the future!
- Localization support
- Tracker visualization
- Debugging options
- ..and many more things coming soon!
